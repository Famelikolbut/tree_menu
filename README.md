# Django Tree Menu

Это Django-приложение реализует древовидное меню с поддержкой вложенности, активных элементов и нескольких меню на одной странице. Меню реализовано через `template tag` и хранится в базе данных. Активный пункт определяется по текущему URL, а всё, что над ним, разворачивается, как и первый уровень под ним. Отрисовка каждого меню выполняется ровно одним SQL-запросом. Меню редактируются через стандартную админку Django, без дополнительных библиотек.

# Инструкция для запуска проекта

1. Клонирование репозитория

```
git clone <URL репозитория>
cd <название репозитория>
```

2. Создание виртуального окружения и установка зависимостей

```
python3 -m venv venv   
source venv/bin/activate  # venv\Scripts\Activate
pip install -r requirements.txt
```

Примените миграции:
```
python manage.py migrate
```

Создайте суперпользователя:
```
python manage.py createsuperuser
```

Запустите сервер разработки:
```
python manage.py runserver
```

Настройка меню:

Через админку создайте меню с названиями main_menu, footer_menu, side_menu (или любыми другими). Добавьте пункты (MenuItem) с заголовком (title), URL (либо явным url, либо named_url), укажите родителя (если это вложенный пункт) и задайте порядок сортировки (order).



Для отображения меню в нужном месте страницы подключите теги:
```
{% load menu_tags %}
```

И вставьте вызов тега с нужным именем меню:
```
{% draw_menu 'main_menu' %}
{% draw_menu 'footer_menu' %}
{% draw_menu 'side_menu' %}
```
